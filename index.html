Backup for server Heraclitus

A personal server-backup application operated by its account owner. It uses rclone and encrypted Restic repositories to copy backup data to the owner's Google Drive.

This application is for the owner's private use. It is not a public backup service and does not offer account registration.

Google Drive access is used to create, list, read and verify backup files and to maintain the owner's backup repositories. Backup contents are encrypted before upload. Repository passwords are kept separately from the encrypted backup data.
